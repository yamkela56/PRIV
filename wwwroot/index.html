Privacy-First Booking & Scheduling

PRIV is a privacy-focused appointment scheduling website that allows users to request meetings without exposing another user's calendar. Instead of showing the owner's schedule, the system only displays calculated available time slots after permission has been granted. The system prioritizes privacy while still making scheduling simple.

How PRIV Works

  1. Search & Connect: Search for users by unique @username and send an Access Request.
  2. Connection Approval: User B approves or declines the request.
  3. Privacy Calculation: Only available slots are calculated and rendered. Private calendar titles stay hidden.
  4. Location Selection: User A suggests 1–3 locations. User B picks one upon approval.
